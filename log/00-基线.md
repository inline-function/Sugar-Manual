# 00 · 基线审计 —— SfA 回迁前的现状（2026-11-03）

> 结论先行：**设备上的应用 = subl 生成的 Compose 骨架 + 3400 行宿主 Kotlin 引擎**。
> JS 双胞胎（assets/app.js）在 WebView 里活着，但没人消费它的状态——它退化为纯测试预言机。

## 1. 管线（docs/工程管线.md 定义的名义流程）

```
app/*.subl（视图 + 逻辑同源）
  ├─ JS 等价链：runcompile.bat → app/out.js（→ 复制为 assets/app.js）
  │    node app/v2-assert.js / out.test.js → 设备无关回归
  └─ @compose 通路：out/Home.kt … → sync-gen.js 补丁 → gen/ → runbuild → APK
```

名义口径：**JS 是逻辑真相源，宿主镜像，sync-gen 落盘**。

## 2. 设备上的实际接线（本次实测）

`gen/Home.kt`（507 行，home.subl 7 个 @compose 段生成，sync-gen 补丁后）：

| 调用 | 数量 | 说明 |
|---|---|---|
| DshComposeHost.act | 46 | 所有事件直接路由进宿主纯 Kotlin |
| boolArg | 47 | 宿主状态 |
| strArg | 34 | 宿主状态 |
| stateOf / pushState / callJs | **0 / 0 / 0** | **JS 槽位机制完全没被接上** |
| Subl_* 宿主组合函数 | 4 个 | EffectTags / RecCard / Cart / PackSheet / CalendarPage |

`DshComposeHost.kt`：`act()` 全部纯 Kotlin 实现（全文件 callJs 出现 1 次 = 声明行）。
`effectTags()`、`chartLabels/Series`、`typDose`、`builtinNeuros`、包定义、日历全部宿主计算。

→ **WebView 里的 JS 引擎在设备上是空转的**：它跑 main()、算 content()、pushState，
但 gen 侧没有任何 stateOf 槽位接收，也没有 callJs 回调它。它只剩"等价链预言机"这一个职能。
