# 语法糖手册

> 一个用于给精神障碍患者辅助用药情况的安卓端APP

## UI

应用整体采用MD风格设计。

点进去的首页，上半部分是一个时间线折线图，显示药物的估算血药浓度；中间部分放预警栏；下半部分是一个列表，列出服用的药品，按最近时间排序从上到下。

首页顶栏左边显示“语法糖手册”，文本的下面有淡淡的副标题“Vx.x”，表示版本。顶栏的右边有文档与设置两个图标按钮。

在应用的右下角，有一个悬浮圆角按钮“服用药物”。

## 预警

预警分为提示|警告|危险三个等级。

### 不良反应预警

联用药品中有相同不良反应的预警

权重：罕见(1)、少见(2)、常见(3)、十分常见(5)

预警所需权重：提示(3)、警告(5)、危险(7)

### 代谢相互作用

联用药品中有酶相互作用的预警

权重：弱效(1)、中效(2)、强效(3)、极强(5)

预警所需权重：提示(1)、警告(3)、危险(5)

## 药物资料

用户可以自定义药物，以下是一个药物的资料格式化，以氟伏沙明为例填写。

### 基本

药名：氟伏沙明

管理分类：处方药

标签：选择性血清素再摄取抑制剂、SSRIs、五朵金花、抗抑郁药、抗强迫药、抗焦虑药、助眠药

说明：氟伏沙明是一种选择性血清素再摄取抑制剂类抗抑郁药，主要用于治疗抑郁症和强迫症。它通过抑制中枢神经突触对血清素的再摄取，提高突触间隙递质浓度，从而发挥抗抑郁、抗焦虑作用。常见不良反应为恶心、呕吐等胃肠道症状，通常服药两周后减轻。

### 药效

> 极弱、弱效、中效、强效、极强

+ 【强效】血清素转运体抑制

+ 【极弱】正肾素转运体抑制

+ 【强效】激动 σ1 受体

+ 【极弱】α1-肾上腺素能拮抗

### 酶

经[CYP2D6/CYP1A2]代谢

+ 【强效】CYP1A2可逆性抑制

+ 【强效】CYP2C19可逆性抑制

+ 【弱效】CYP2C9可逆性抑制

+ 【弱效】CYP3A4可逆性抑制

### 药代动力学

> 每个给药途径与药型可以单独创建一个资料

给药途径：口服

药型：常释

半衰期：15小时

达峰时间：不稳定

清除动力学：一级

剂量曲线：对数

生物利用度：50%
