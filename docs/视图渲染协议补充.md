# 视图渲染协议补充（Chart / FloatingButton / Box.scrollable）

本文件补充 `android doc/安卓标准库.md` 的视图渲染协议，描述本任务（t29）为 Sugar-Manual 首页新增/扩展的三个视图的 **JSON 契约（JS 端 @view 结构体 → layout 桥 JSON.stringify）** 与 **KT 端 DshBridge 渲染分支**。语言侧视图定义在 `app/Chart.subl`、`app/FloatingButton.subl`、`app/Box.subl`（与 SfA 仓库 android stdl 同步）。

## 0. 通用序列化约定（已有机制的复述）

- `@view struct` 的字段按名序列化为 JSON 对象，并附加 `tag`（结构体名）、`children`（body 内的子视图数组，由 @view 处理器擦除 body 注入）、`recomposion`（重组回调 id，KT 端增量 diff 用）。
- `layout(content)` 桥调用：`__dshAndroid("layout", [JSON.stringify(content(null))])`。
- KT 端按 `tag` 分派（`DshBridge.buildView`），未识别 tag 回退为 Text。颜色统一 `#RRGGBB`（`parseColor`）。

## 1. Chart（折线/柱状图）

**语言侧**（`app/Chart.subl`）：

```subl
@view struct Chart(
    kind: Str = "line",          // "line" 折线（默认）| "bar" 柱状
    points: List[Rat] = emptyList(),  // Y 值序列（如 pk.seriesValues 浓度序列）
    labels: List[Str] = emptyList(),  // 逐点 X 轴标注（如 seriesLabels 的 "0h".."48h"）
    color: Str = "",             // "#RRGGBB" 主色（默认 KT 端主题紫 #7C4DFF）
    modifier: Modifier = Plain(),
    body: () => Null = fun(): Null { null }
)
```

**JSON 示例**：

```json
{ "tag": "Chart", "kind": "line",
  "points": [50.0, 41.56, 34.55], "labels": ["0h", "4h", "8h"],
  "color": "#6750A4", "modifier": { "tag": "Plain" },
  "children": [], "recomposion": "Chart$1", "__ord": 1 }
```

**KT 渲染分支**：`buildChart(node)` → `ChartView`（自绘 Canvas，零第三方依赖）：
- `kind="line"`：折线 + 数据点圆点 + 渐变填充；`kind="bar"`：柱状。
- `points` → FloatArray；`labels` 非空时绘制 X 轴文字；Y 轴按 min/max 自适应（span 下限 0.0001f），4 条网格线。
- onMeasure：期望 180dp × 160dp（resolveSize 协商）。

## 2. FloatingButton（MD 悬浮圆角按钮）

**语言侧**（`app/FloatingButton.subl`）：

```subl
@view struct FloatingButton(
    label: Str = "",             // 按钮文字（亦可经 body 装文本子视图，与 Button 同）
    color: Str = "#6750A4",      // 主色（Material 紫）
    cornerRadius: Nat = 28,       // 圆角半径（dp 级，28 约正圆角）
    onClick: (Any) => Null = fun(_: Any): Null { null },
    modifier: Modifier = Plain(),
    body: () => Null = fun(): Null { null }
)
```

**JSON 示例**：

```json
{ "tag": "FloatingButton", "label": "", "color": "#6750A4", "cornerRadius": 28,
  "onClick": "FloatingButton_onClick_3", "modifier": { "tag": "Plain" },
  "children": [ { "tag": "Text", "text": "＋ 服用药物" } ],
  "recomposion": "FloatingButton$1", "__ord": 1 }
```

**KT 渲染分支**：`buildFloatingButton(node, children)` → `MaterialButton`：
- 文字 = body 子视图提取（`extractText(children)`）回退 `label` 字段；
- `cornerRadius` → `MaterialButton.cornerRadius`；`color` → `backgroundTintList`（ColorStateList）；
- `onClick` 字段为回调 id 字符串（与 Button 同机制）：点击时执行 `try{ globalThis.__dshFn_<id>(); }catch(e){...}`。

**悬浮定位**（`buildBox` 扩展）：当一个 Box 的子视图中含 tag=`FloatingButton` 时，该 Box 改用 **FrameLayout** 渲染——
1. 非悬浮子视图照常竖排进 LinearLayout，宽 MATCH_PARENT；
2. 每个 FloatingButton 子视图从线性流中**抽出**，以 FrameLayout.LayoutParams(Gravity **BOTTOM|END**, 边距 16dp) 叠入 FrameLayout；
3. 结果：FAB 悬浮于整页内容右下角（MD FAB 定位），不参与线性布局流。

## 3. Box.scrollable（可滚动容器）

**语言侧**（`app/Box.subl` 新增字段）：

```subl
@view struct Box(
    modifier: Modifier = Plain(),
    contentAlignment: Alignment = Center(),
    orientation: Str = "vertical",   // "vertical"（默认）/ "horizontal"
    backgroundColor: Str = "",
    scrollable: Bool = false,        // true：内容超出可视区域时可滚动
    body: () => Null = fun(): Null { null }
)
```

**JSON 示例**：

```json
{ "tag": "Box", "orientation": "vertical", "backgroundColor": "",
  "scrollable": true, "children": [], "recomposion": "Box$1", "__ord": 1 }
```

**KT 渲染分支**（`buildBox`）：`scrollable=true` 时，LinearLayout 包进 `ScrollView`（纵向）/ `HorizontalScrollView`（横向），宽 MATCH_PARENT——整页三段式布局内容超高即可滚动。与 FloatingButton 的 FrameLayout 包装互斥（FAB 优先）。

## 4. 预警横幅（无新视图——纯组合）

预警栏由现有视图**组合**实现，不需要新视图类型，便于其他工程复用：

```subl
Box(backgroundColor = levelBg(maxAlertLevel(adr, metab))) {
    Text(text = concat("⚠ ", bannerHead(adr, metab)), color = levelFg(...), bold = true)
    triggerRows(append(adr.items, metab.items))   // 每行 Text「名称  权重」
}
```

着色表（MD 色板）：见 [使用说明.md](使用说明.md) §1。工程上未引入 `AlertBanner` 视图类型：色彩/文案完全由数据驱动（levelBg/levelFg 纯函数），组合 Box+Text 已满足「差异化着色横幅」需求，且保持 stdl 视图集合最小化。
