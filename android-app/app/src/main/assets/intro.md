## 神经递质

> 人的**意识**，很大程度上依托于一堆不断变化、彼此传递的化学分子——**神经递质**。它们不是意识本身，却像是意识得以流动的那条河。

| 神经递质 | 作用               | 过少                                         | 过多                                                           |
|:-------- |:------------------ |:-------------------------------------------- |:-------------------------------------------------------------- |
| 多巴胺   | 奖赏、动机         | 动机缺乏、快感缺失、情绪低落；**”帕金森病“** | 欣快；**”精神分裂症“的阳性症状**、**”双相情感障碍“的躁狂发作** |
| 正肾素   | 警觉、应激         | 注意力涣散、抑郁、疲劳                       | 焦虑、高血压、头痛、呕吐                                       |
| 血清素   | 缓冲情绪、睡眠     | 抑郁、焦虑、强迫、睡眠障碍                   | **“血清素综合征”**                                             |
| 乙酰胆碱 | 注意力、记忆       | **”抗胆碱能危象“**                           | **“胆碱能危象”**                                               |
| 谷氨酸   | 学习、记忆         | **”阿尔茨海默症“**                           | **”阿尔茨海默症“**                                             |
| GABA     | 镇静               | 焦虑、失眠、心悸                             | 嗜睡、头晕、呼吸抑制                                           |
| 内啡肽   | 镇痛、奖赏         | 痛觉敏感、情绪低落                           | 止痛、欣快、呼吸抑制                                           |
| \*褪黑素 | 调节睡眠-觉醒      | 入睡困难、睡眠质量差、昼夜节律紊乱           | 嗜睡                                                           |
| \*食欲素 | 调节觉醒、清醒状态 | **”发作性睡病“**                             | 失眠、睡眠片段化                                               |
| \*P物质  | 传递痛觉信号       | 欣快，镇静，镇痛                             | 慢性疼痛；**”肠易激综合征“**                                   |

### \*血清素综合征

**血清素综合征（血清素中毒）**是血清素系统亢进的急性不良反应，极其严重的情况下可能危及生命，是抑郁症患者与oder们常见非自然死亡原因之一。

它通常表现为三个系统的异常，医学上称为**“三联征”**：

- **精神状态改变**：焦虑、烦躁、幻觉、谵妄。
- **自主神经功能亢进**：心动过速、血压波动、大量出汗、瞳孔放大、腹泻、寒战。
- **神经肌肉异常**：震颤、反射亢进、肌肉僵硬、抽搐。

| 程度     | 症状                                                             | 主观                                                               |
|:-------- |:---------------------------------------------------------------- |:------------------------------------------------------------------ |
| **轻度** | 间歇性震颤、轻微不适、坐立不安、焦虑                             | 可能不被重视，或仅感觉不适。通常停用致病药物即可缓解。             |
| **中度** | 持续性阵挛、震颤、心动过速、高血压、发热、出汗、激越、焦虑、幻觉 | 症状明显，对患者造成显著困扰，需要进行处理，但通常**无生命危险**。 |
| **重度** | 高烧、谵妄、昏迷                                                 | 病情可导致多器官功能衰竭，甚至死亡。                               |

### \*抗胆碱能危象

**抗胆碱能危象（抗胆碱能中毒）**是乙酰胆碱被过度阻断的急性状态。乙酰胆碱负责认知，过度阻断会让意识陷入混乱的谵妄，滥用苯海拉明等谵妄剂会带来此危象。*干如枯骨，红如甜菜，盲如蝙蝠，疯如帽匠，热如野兔。*

它通常按**三组表现**来描述：

- **外周抗毒蕈碱样**：皮肤温暖干燥、口干、瞳孔散大、视物模糊、心动过速、高热、尿潴留、肠鸣音减少或肠梗阻。
- **中枢抗胆碱能**：谵妄、意识混乱、激越、幻觉、抽搐、昏迷。
- **交感相对兴奋样**：心动过速、血压升高、瞳孔散大。

| 程度     | 症状                                           | 主观                                           |
|:-------- |:---------------------------------------------- |:---------------------------------------------- |
| **轻度** | 口干、皮肤干、瞳孔稍大、轻度心动过速、轻度烦躁 | 口渴、脸红、看不清近物、心跳偏快，像“上火”。   |
| **中度** | 谵妄、幻觉、高热、尿潴留、肠鸣音消失、心动过速 | 意识模糊、看到不存在的东西、肚子胀、尿不出来。 |
| **重度** | 抽搐、昏迷、严重高热、心律失常                 | 昏迷；可因心律失常或高热致命。                 |

### \*胆碱能危象

**胆碱能危象（乙酰胆碱中毒）**是乙酰胆碱系统亢进的急性不良反应，常见于胆碱酯酶抑制剂过量等。严重可因呼吸肌麻痹死亡。

它通常表现为**三大类表现**：

- **毒蕈碱样**：流涎、流泪、大汗、瞳孔缩小、胸闷气喘、恶心呕吐、腹泻腹痛、心动过缓。
- **烟碱样**：肌束颤动、抽动、肌无力、呼吸肌麻痹。
- **中枢**：头晕、焦虑、谵妄、抽搐、昏迷。

| 程度     | 症状                                                           | 主观                                                             |
|:-------- |:-------------------------------------------------------------- |:---------------------------------------------------------------- |
| **轻度** | 流涎、流泪、出汗、瞳孔缩小、恶心、腹痛、肌束颤动               | 大部分人可能只觉得不太舒服，但仍需处理，因为可能加重。           |
| **中度** | 明显支气管分泌、呼吸困难、呕吐腹泻、肌无力、心率异常、焦虑谵妄 | 喘不上气、肚子绞痛、手脚发软、恐慌，这时需要尽快处理，防止死亡。 |
| **重度** | 呼吸肌麻痹、抽搐、昏迷、呼吸循环衰竭                           | 严重情况下可因呼吸抑制致命                                       |

## 受体与通道

> 受体是细胞上的锁孔，分子可以插入其中，然后改变细胞状态。 同一分子落在不同亚型上，效果可以完全相反。 所以“某种递质让人快乐”这类说法，总是过于粗糙。

下面是常见的受体，其中斜体是我们强调的作用：

| 家族       | 亚型              | 激动时的主要效应                         |
|:---------- |:----------------- |:---------------------------------------- |
| **GABA**   | GABA-A            | *镇静*、抗焦虑、肌松、抗惊厥             |
|            | GABA-B            | 肌松、镇咳、部分镇痛                     |
| **谷氨酸** | NMDA              | *感知世界*、学习记忆、突触增强           |
| **阿片**   | μ                 | *镇痛*、欣快、镇静、便秘、缩瞳、呼吸抑制 |
|            | κ                 | *镇痛*、烦躁、低落、致幻                 |
|            | δ                 | *镇痛*、抗抑郁                           |
| **多巴胺** | D1 样（D1/D5）    | *欣快*、动机增强、躁动                   |
|            | D2 样（D2/D3/D4） | *致幻*                                   |
| **血清素** | 5-HT1A            | *抗抑郁*、抗焦虑                         |
|            | 5-HT2A            | *致幻*                                   |
|            | 5-HT2C            | 抑制食欲、影响情绪                       |
|            | 5-HT3             | 呕吐                                     |
|            | 5-HT4             | 促进胃肠动力                             |

**备用受体**：细胞表面有大量的受体，但只需要激活其中一小部分（有时不到 10%），就能产生最大效应。多出来的受体就是"备用的"——它们不干活，但让系统对低浓度药物更敏感。想象一个体育场有 10000 个出口，但只需要打开 5 个，人群就能全部疏散。多出来的 9995 个出口就是"备用的"——即使药物只占了其中一小部分，疏散（最大效应）也已经完成了。

### 激动与拮抗

> **竞争性拮抗**：拮抗剂和激动剂抢同一把椅子，谁多谁赢。
> **非竞争性拮抗**：拮抗剂不抢椅子，而是把椅子锁死，激动剂坐上去也摇不动。
> **不可逆拮抗**：拮抗剂不讲武德，直接把椅子砸了，只能等新椅子送来。

| 方式             | 解释                                                                             |
|:---------------- |:-------------------------------------------------------------------------------- |
| **完全激动**     | 把受体完全打开，效果拉满。                                                       |
| **竞争性拮抗**   | 和激动剂抢同一个结合位点，增加激动剂浓度可以"挤走"拮抗剂                         |
| **非竞争性拮抗** | 结合在别构位点，改变受体构象让激动剂无法激活，增加激动剂浓度无效                 |
| **\*不可逆拮抗** | 与受体共价结合，"焊死"在受体上，只能等新受体合成才能恢复                         |
| **\*部分激动**   | 只能把受体打开一点点，效果有限；如果旁边有完全激动剂，它反而会占着位置压低效果。 |
| **\*反向激动**   | 产生与激动相反的效果。                                                           |
| **\*正性变构**   | 不直接开受体，但帮激动剂“推一把”，让它的效果更强。                               |
| **\*负性变构**   | 不直接关受体，但拖激动剂“后腿”，让它的效果变弱。                                 |

### \*受体适应

> 身体永远在往平衡方向修正。用药时它往下压，停药时它往上顶。因此“停药”往往比“用药”更需要谨慎——多数需要长期使用的中枢药物，都要求缓慢减量而非骤停

| 现象 | 含义         | 临床后果                             |
| ---- | ------------ | ------------------------------------ |
| 脱敏 | 受体反应减弱 | 快速耐受，需要加量才能达到原来的效果 |
| 敏化 | 受体反应增强 | 戒断、停药反跳；慢性疼痛、成瘾渴求   |
| 下调 | 受体数量减少 | 长期用药后效果衰减                   |
| 上调 | 受体数量增加 | 突然停药出现反跳，需缓慢减量         |

### \*通道

| 通道 | 作用                                                   |
| ---- | ------------------------------------------------------ |
| 钠   | 动作电位的上升段，兴奋的产生与传导                     |
| 钙   | 触发递质释放和肌肉收缩，参与心脏起搏节律               |
| 钾   | 电压门控管复极化，一直开着的管静息电位；影响心肌不应期 |
| 氯   | 抑制性，让细胞更难放电                                 |

## 酶

> 酶是细胞里的“工人”，是一种特殊的有机催化剂，专门负责把分子拆开或拼起来。在“信号”和“药物”这两件事上，它们主要干三样活：把信使拆掉（让信号停下来）、把信使造出来（让信号发得出）、把外来物清理掉（代谢并排出药物）。

### 作用

> 顺带一提，**再摄取转运体**不是酶，但常和酶一起讲。它不拆解递质，只是把完整的递质分子搬回神经元内，供重新利用或再被酶拆解。

| 工作 | 介绍             |
| ---- | ---------------- |
| 制造 | 制造递质         |
| 拆解 | 拆解递质         |
| 代谢 | 改变药物分子形态 |

### CYP 酶

> CYP是一个酶家族，也是肝脏里的“拆解车间”，绝大多数外来物质（药物、酒精、食物里的成分）进来后，都要先经过它改造一遍，才能被排出体外。所以它既是很多药物的“出口”，也是药物相互作用的“入口”。

| 常见工作         | 解释                                                                                 | 结果                                               |
| ---------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------- |
| 亲水化           | 药物大多亲脂（好进细胞），但亲脂就不好从尿里排走；CYP 给它挂上羟基等基团，让它变亲水 | 便于排出，通常**失去活性**                         |
| 激活前体药       | 有些药吃下去是没用的“半成品”，必须被 CYP代谢变成有用的药物分子                       | 代谢＝**起效**，不是失效                           |
| \*交给第二相加工 | CYP 属于第一相，改完之后常由 UGT、SULT 等再挂一个大分子，彻底水溶化                  | 完成清除                                           |
| \*造出有害中间物 | 少数情况下代谢产物比原药更毒                                                         | 药物性肝损伤的重要机制之一（如大剂量对乙酰氨基酚） |

### 抑制与诱导

CYP 的种类有限，但药物成千上万——**很多药共用同一个酶**，于是要么互相抢位，要么互相改变酶的数量。

| 现象       | 机制             | 特点                                         |
| ---------- | ---------------- |:-------------------------------------------- |
| 可逆抑制   | 让酶暂时降低活性 | 可逆抑制在停用酶抑制剂后可以快速恢复效果     |
| 不可逆抑制 | 直接使酶永久失活 | 不可逆抑制会摧毁酶，恢复功能要等新的酶造出来 |
| 诱导       | 使得细胞多造酶   | 诱导通常生效慢                               |

### \*多态性

| 类型             | 特点                             | 后果                                                             |
| ---------------- | -------------------------------- | ---------------------------------------------------------------- |
| 慢代谢型         | 酶活性很低或缺失                 | 药物清除慢，容易蓄积中毒，需要减量                               |
| 中间型／快代谢型 | 活性居中或正常                   | 常规剂量通常合适                                                 |
| 超快代谢型       | 酶活性异常高（如基因拷贝数增多） | 常规剂量可能完全没效果；若是前体药，反而可能生成过多活性物而中毒 |

## 药代动力学

> 药不是被吃下就开始干活——它要经历一场旅行：**吸收、分布、代谢、排泄**，研究这四个环节，就是**药代动力学**。

### 给药途径

> 药物口服后要先经过肝脏代谢一部分才能发挥作用，称为**首过效应**，某些药物（如硝酸甘油）甚至因为首过效应而导致口服无法发挥作用。

| 途径           | 怎么进               | 起效速度               | 典型场景                 |
| -------------- | -------------------- | ---------------------- | ------------------------ |
| **口服**       | 经口服用             | 慢（30 分钟 ~ 数小时） | 大多数药物               |
| **颊内含服**   | 含在口腔中           | 较快（几分钟）         | 润喉糖                   |
| **舌下含服**   | 含在舌下，经黏膜吸收 | 较快（几分钟）         | 硝酸甘油、某些苯二氮䓬   |
| **吸入**       | 经肺泡直接吸收       | 极快（几秒）           | 烟草、大麻、挥发性麻醉剂 |
| **鼻黏膜给药** | 鼻黏膜吸收           | 较快（几分钟）         | 催产素鼻喷、氯胺酮鼻喷剂 |
| **直肠给药**   | 栓剂经直肠黏膜吸收   | 中等                   | 呕吐、昏迷、拒药时       |
| **静脉注射**   | 直接进血管           | 最快（几秒）           | 急诊镇静、麻醉诱导       |
| **肌肉注射**   | 打进肌肉组织         | 快（几分钟）           | 急性躁动、长效针剂       |
| **透皮**       | 贴皮肤慢慢渗         | 慢但平稳               | 尼古丁贴、抗抑郁药贴剂   |

### 血药浓度

> 药物进入血液后的浓度，是药效与毒性的直接指标。太低没效果，太高可能中毒。它随时间变化，受吸收、分布、代谢、排泄共同影响。

| 要点         | 说明                               |
| ------------ | ---------------------------------- |
| 有效浓度范围 | 是药物起作用的浓度                 |
| 达峰时间     | 血药浓度达到最高值的时间           |
| 峰浓度       | 血药浓度的最高值                   |
| 谷浓度       | 下次给药前的最低浓度               |
| 稳态浓度     | 连续给药后，血药浓度趋于稳定的水平 |

### 半衰期

> 血药浓度降一半所需的时间，决定药物的服用频率与戒断反应。

| 半衰期          | 服药频率        | 举例                                 |
| --------------- | --------------- | ------------------------------------ |
| 短（< 6 小时）  | 一天 3–4 次     | 阿普唑仑                             |
| 中（6–24 小时） | 一天 1–2 次     | 帕罗西汀                             |
| 长（> 24 小时） | 一天 1 次或更少 | 氟西汀（活性代谢物 t½ 可达 7–15 天） |

一般经过五个半衰期，我们说药物被清除。

### 剂型

> 剂型决定药释放的节奏。单方制剂意思是只有一种有效药物分子成分的药片，复方制剂相反，是有多种药物分子的药片，比方说单方右美沙芬和复方愈美片（右美沙芬-愈创木酚甘油醚），其中前者是第二类精神药品，后者是处方药。

| 剂型              | 特点                              | 释放节奏                     | 临床意义                                         |
| ----------------- | --------------------------------- | ---------------------------- | ------------------------------------------------ |
| 普通片            | 吞下去就溶                        | 血药浓度先冲上去再慢慢掉下来 | 一天可能要吃两三次                               |
| 缓释/控释片       | 药被包在“慢溶壳”里，慢慢放        | 释放平稳，血药浓度更稳定     | 一天一次就够了                                   |
| \*舌下含片/口崩片 | 避开首过效应                      | 起效更快                     | 适合需要快速起效的场景                           |
| \*透皮贴剂        | 持续稳定释放                      | 经皮缓慢吸收，血药浓度平稳   | 适合需要长期平稳血药浓度的场景                   |
| \*长效针剂        | 微球或油剂，一针管 2–4 周甚至更久 | 持续缓慢释放                 | 抗精神病药常用；解决“忘了吃药”或“不肯吃药”的问题 |

### \*生物利用度

> 药物被吸收进入体循环的速度与程度，通常用百分比表示。静脉注射的生物利用度是 100%（因为直接进血），其他途径都低于这个值。

| 途径           | 生物利用度 | 原因                       |
| -------------- | ---------- | -------------------------- |
| 静脉注射       | 100%       | 直接进血，无损耗           |
| 舌下/吸入/透皮 | 较高       | 绕过首过效应               |
| 吞服           | 因药而异   | 受首过效应、肠道吸收率影响 |

为什么生物利用度重要？ 它直接决定吃多少才够。同一种药，吞服和注射的剂量可能差好几倍。

### \*分布

药进了血，不是均匀地撒在全身。它会：

- **和血浆蛋白结合**（主要是白蛋白）——结合的部分"暂时失效"，只有游离的部分能干活。
- **穿过血脑屏障**——精神科药物必须能过这一关，否则到不了大脑。脂溶性高的分子更容易过去。
- **蓄积在脂肪组织**——有些药（如地西泮）脂溶性高，会"藏"在脂肪里慢慢释放，半衰期被拉长。

这也是为什么**肥胖、低蛋白血症**（如肝硬化患者）会显著改变药效——药在血里的"自由身"比例变了。

### \*代谢

肝脏是主战场，**CYP450 酶系**是主力（详见"酶"节）。精神科药物之间最麻烦的相互作用就出在这里：

- **酶诱导剂**（如卡马西平、圣约翰草）：把 CYP 酶"激活"，让其他药代谢加快→药效变弱。
- **酶抑制剂**（如氟西汀、帕罗西汀、葡萄柚汁）：把 CYP 酶"堵住"，让其他药代谢变慢→血药浓度飙升，可能中毒。

> 这就是为什么吃 SSRI 的人不能随便加别的药，也不能猛喝葡萄柚汁的原因。

### \*排泄

主要走两条路：

- **肾脏**（尿液）：水溶性代谢产物经肾小球滤过排出。肾功能不好的人，药排不出去，容易蓄积中毒。
- **胆汁/粪便**：部分药物经肝脏排入胆汁，随粪便排出。

## 量效关系

> 效价是"钥匙转动的灵敏度"，效能是"门锁最终能开到的最大角度"。 一把灵敏度极高但只能开一条缝的钥匙（高效价、低效能），和一把需要使劲转但能完全打开的钥匙（低效价、高效能），在实际使用中各有优劣。

药物在体内的效果，不是"有或无"的开关，而是"多或少"的渐变。剂量增加，效果逐渐增强——但不会无限增强，最终会到达一个平台。

| 概念       | 简介                                               | 临床意义                                 |
| ---------- | -------------------------------------------------- | ---------------------------------------- |
| 效价       | 产生同等效应所需的剂量，越小效价越高               | 决定"吃多少"，但不决定"效果上限"         |
| 效能       | 药物能产生的最大效应                               | 决定"这个药到底管不管用"，比效价更重要   |
| 半数有效量 | 50% 最大效应对应的剂量                             | 衡量效价的常用指标                       |
| 半数致死量 | 50% 实验动物死亡的剂量                             | 衡量急性毒性的指标（临床很少直接用）     |
| 治疗指数   | 治疗指数 = 半数致死量 / 半数有效量，数值越大越安全 | 锂盐 TI 很窄（安全窗小），地西泮 TI 较宽 |
| 安全范围   | 最小有效浓度与最小中毒浓度之间的宽度               | 比 TI 更贴近临床，反映实际用药的安全余量 |

## 盐

> 我经常看到很多人称呼药物时会简称。比方说对于酒石酸唑吡坦这种长的名字，但是他们缩掉了原本药物分子的名字，叫它酒石酸。这相当于叫梁文峰为梁，要知道世界上有很多姓梁的人。

把药物分子变成盐，就像给一个不溶于水的游客发一本“护照”——它本身还是那个人，但过海关、坐飞机、住酒店都方便多了。

**药物分子游离碱（或游离酸）+ 酸（或碱）→ 盐**

盐型不改变分子跟受体结合的能力，它改变的是**物理性质**：溶解度、溶出速度、稳定性、吸湿性、熔点、口味、注射痛……这些东西听起来像“包装问题”，但它们能直接决定一个分子能不能成为药、成为什么剂型、以及能不能在货架上活到被吃下去的那天。

一种酸可以配多种药物分子，比方说丙戊酸可以配钠和镁；一种药物分子也可以配多种酸，比方说喹硫平可以配富马酸和盐酸。

### 常见盐型

| 盐型         | 代表药物                     | 优点               | 缺点                               |
|:------------ |:---------------------------- |:------------------ |:---------------------------------- |
| **盐酸盐**   | 氯胺酮、曲马多、哌甲酯       | 水溶性好，最通用   | 刺激性大                           |
| **氢溴酸盐** | 右美沙芬                     | 水溶性好，吸收快   | 溴离子高剂量可能引起溴中毒         |
| **硫酸盐**   | 苯丙胺、吗啡                 | 水溶性好，起效快   | 容易吸潮，稳定性差                 |
| **马来酸盐** | 氟伏沙明、依那普利、氯苯那敏 | 稳定性好，不易吸潮 | 酸性较强，注射可能刺激，水溶性一般 |
| **枸橼酸盐** | 坦度螺酮、芬太尼             | 胃肠刺激小         | 水溶性一般，影响口感               |
| **酒石酸盐** | 唑吡坦、肾上腺素、美托洛尔   | 稳定性不错         | 水溶性一般                         |
| **富马酸盐** | 喹硫平、比索洛尔、酮替芬     | 不吸潮             | 水溶性较差                         |

## 手性

> 你的左手和右手，看起来一模一样，但你永远无法通过旋转把它们完全重叠。分子也有这种“左右手”特性，我们称之为**手性**。而同一个分子的左手和右手，在体内可能是两种完全不同的药：一个治病，一个致命。

一个分子如果和它的镜像**不能完全重叠**，它就是手性的。这对镜像分子叫**对映体**。

比如**沙利度胺**——一个对映体是镇静剂，另一个是婴儿致畸剂。这不是玩笑，是真实发生过的悲剧。

等量的右旋体和左旋体混合，整体旋光性相互抵消，称为**消旋体**。

| 药物             | 核心要点                                                     |
| ---------------- | ------------------------------------------------------------ |
| **艾司西酞普兰** | 外消旋西酞普兰中，S-型效力是R-型的30倍以上，直接拆出S-型上市 |
| **右哌甲酯**     | 外消旋哌甲酯中，d-型是主要活性成分，拆出右旋体               |
| **右佐匹克隆**   | 佐匹克隆的右旋体代谢更快、残留更少，优于消旋体               |
| **艾司氯胺酮**   | 氯胺酮的S-对映体，麻醉/抗抑郁效力更强，副作用更少            |

对映体的差异不只是“一个有效一个无效”，它们可以在多个层面上不同：

| 差异类型       | 机制                                    | 例子                                                   |
|:-------------- |:--------------------------------------- |:------------------------------------------------------ |
| **药效差异**   | 只有一种对映体能和受体结合              | 艾司西酞普兰对SERT的抑制效力是R-西酞普兰的**30倍以上** |
| **药效反转**   | 一个对映体是激动剂，另一个是拮抗剂      | 某些阿片类对映体在不同受体上作用相反                   |
| **代谢差异**   | 一个对映体被CYP快速代谢，另一个半衰期长 | 华法林的S-对映体抗凝活性是R-的**3至5倍**               |
| **\*毒性差异** | 一个对映体产生毒性代谢物                | 沙利度胺的S-对映体致畸                                 |
| **\*转运差异** | 一个对映体是P-糖蛋白底物，另一个不是    | 影响血脑屏障通透性                                     |

## \*血脑屏障与肠道神经系统

> 神经元并不是彼此孤立的岛屿。大脑被一层极其挑剔的边界包裹着，而肠道里还藏着另一套能够独立运转的神经系统。它们共同决定了一件事：化学信号能走到哪里，又必须在哪里止步。

### 血脑屏障

> 血液里流淌着营养，也流淌着毒素、病原体和无数药物。血脑屏障的存在，就是为了让前者进来、后者止步。

#### 通透规则

> 为什么“能不能入脑”常常是中枢药物成败的第一道关卡——常被引用的估计是，绝大多数小分子药物难以有效穿过这道屏障。

| 现象           | 通过物质                     | 举例                                   |
| -------------- | ---------------------------- | -------------------------------------- |
| 自由扩散       | 脂溶性强的小分子             | 氧气、二氧化碳、乙醇、尼古丁           |
| 载体转运       | 脑必需的“口粮”               | 葡萄糖（GLUT1）、部分氨基酸、核苷      |
| 外排泵主动清出 | 把误入的药物泵回血液         | P-糖蛋白，也是肿瘤“多药耐药”的原因之一 |
| 基本进不来     | 大分子、多数蛋白、多数抗生素 | 胰岛素、大部分单克隆抗体需特殊给药途径 |

### 肠道神经系统

> 它常被称作“第二大脑”——这个说法并不夸张：肠道内的神经元数量以亿计，甚至超过脊髓，并且能在没有中枢参与的情况下独立完成反射。

#### 受体与递质

| 神经递质 | 作用             |
| -------- | ---------------- |
| 乙酰胆碱 | 引起蠕动反射     |
| P物质    | 参与蠕动反射     |
| 血清素   | 启动蠕动反射     |
| 正肾素   | 抑制肠神经元活动 |
| 阿片肽   | 抑制蠕动反射     |
| 一氧化氮 | 松弛括约肌       |

## \*药品简介

> 我们按主观效应为药品分类，简单讲解常见的精神活性物质。

### 迷幻剂

> 例如LSD，二丙基色胺，唑吡坦

迷幻剂是一类可以造成强烈幻觉的药剂，与解离剂、谵妄剂同属致幻剂。迷幻剂下分血清素能迷幻剂与非血清素能迷幻剂，血清素能迷幻剂主要激动5-HT2A受体以发挥迷幻效果，非血清素能迷幻剂则是不以激动5-HT2A为主要机理。迷幻剂没有成瘾性，并且容易坏旅行导致产生对迷幻剂的厌恶。

### 解离剂

> 例如氯胺酮，美金刚，右美沙芬，愈创木酚甘油醚，地佐环平，金刚烷胺

解离剂是一类让人产生轻飘飘的解离性麻醉效果的药剂，与迷幻剂、谵妄剂同属致幻剂。NMDA受体负责认知世界，解离剂通过拮抗NMDA受体发挥解离作用，让人断开五感。高强度解离可能会引发一种叫做**K洞**的视觉效应，在啮齿目动物上观察到过量的解离剂会引发不可逆的大脑神经坏死（奥尼尔空洞），但是尚未在人类上观察到该现象。解离剂没有成瘾性，使用解离剂容易会带来头晕，长期使用解离剂会带来慢性现实解体障碍。

### 谵妄剂

> 例如美金刚、金刚烷胺、苯海拉明、苯海索、阿托品、奈福泮

谵妄剂是一类让人意识混乱的药剂，与迷幻剂、解离剂同属致幻剂。乙酰胆碱受体负责维持认知，谵妄剂通过抑制乙酰胆碱，导致发生重度意识混乱，即**谵妄**。谵妄剂没有成瘾性，但是对认知伤害极大，并且体验极其痛苦。

### 抗抑郁、焦虑、强迫剂

> 例如氟伏沙明，氟西汀，舍曲林，西酞普兰，帕罗西汀，文拉法辛，度洛西汀，安非他酮，曲唑酮，米氮平，阿戈美拉汀，艾司氯胺酮，右美沙芬

抗抑郁、焦虑、强迫剂是一类可以抵抗抑郁、焦虑、强迫的药剂。

其中大部分药剂是**血清素再摄取抑制剂**，常见的血清素再摄取抑制剂是**选择性血清素再摄取抑制剂（五朵金花）**，它们仅激动抑制血清素的再摄取；

此外还有**选择性血清素与正肾素再摄取抑制剂**，**选择性正肾素与多巴胺再摄取抑制剂**，**褪黑素受体激动剂**等特殊的抗抑郁药；

不止血清素再摄取抑制剂，还有**三环类抗抑郁剂**与**单胺氧化酶抑制剂**等老式抗抑郁剂，现在基本不使用；

艾司氯胺酮与右美沙芬正在被研究成为新型抗抑郁剂，它们影响谷氨酸受体，抗抑郁效果生效地非常快。除列管的精神药品，抗抑郁剂基本没有心理成瘾性，但是有身体依赖性。

### 抗精神病剂

> 例如喹硫平，奥氮平，氯氮平，利培酮

抗精神病剂是一类可以治疗精神病性症状的药剂，主要用于精神分裂症、双相障碍躁狂发作、妄想性障碍等。典型抗精神病剂主要拮抗多巴胺D2受体，非典型抗精神病剂则通常还拮抗5-HT2A受体，并可能同时影响组胺、α肾上腺素与毒蕈碱受体，所以常带有镇静、体重增加、代谢异常等副作用。抗精神病剂一般没有典型心理成瘾性。

### 心境稳定剂

> 例如碳酸锂，丙戊酸钠，丙戊酸镁

心境稳定剂是一类可以减少心境波动、治疗并预防双相障碍躁狂与抑郁发作的药剂。锂盐的机理较复杂，目前尚未阐明。心境稳定剂基本没有心理成瘾性，但有身体依赖与停药反跳风险，不能突然停用。锂盐治疗窗很窄，容易中毒，需要多喝水。

### 镇静催眠剂

> 例如阿普唑仑，三唑仑，右佐匹克隆，唑吡坦，达利雷生，莱博雷生，喹硫平，阿戈美拉汀

镇静催眠剂是一类可以镇静催眠人的药剂。

**巴比妥类安眠药**是以前常用的安眠药，直接激动GABA受体，但是因为治疗剂量与致死剂量过近，现在已基本不用；

**苯二氮卓类镇静药**是现在常用的镇静催眠药，它正变构GABA受体，相比巴比妥类安全性更高；

**Z类安眠药**是靶点更为干净的安眠药，它主要专精与安眠而不是镇静，但是会有一些奇奇怪怪的副作用，比方说梦游，致幻等；

**食欲素受体拮抗剂**不接触GABA受体，而是聚焦与食欲素受体，食欲素维持人的清醒，食欲素受体拮抗剂把食欲素受体拮抗，令食欲素无法激动食欲素受体，产生自然的入睡效果，缺点是容易做噩梦；

**抗组胺剂**则简单粗暴，它们抑制组胺，产生强烈的镇静效果，缺点是耐药性增加极快；

**褪黑素受体激动剂**则激动褪黑素受体，缺点是效果相较其他镇静催眠药效果较小。

其中大部分药剂是第二类精神药品，有一定成瘾性。

### 抗多动剂

> 例如哌甲酯，苯丙胺，托莫西汀

抗多动剂是一类可以治疗**多动及注意力缺陷障碍**的药剂，它们主要分为兴奋剂与非兴奋剂。其中多为正肾素再摄取抑制剂，哌甲酯类多了个多巴胺再摄取抑制，苯丙胺类则还多了一个多巴胺释放效果。其中大部分药剂是第一类精神药品，有较高的成瘾性，滥用下会带来欣快感。

### 益智剂

> 例如苏糖酸镁，孕烯醇酮，胞磷胆碱钠，呲拉西坦，加兰他敏

益智剂是一类可以提升认知效果的药剂，它们对于普通人可能提升效果不明显，但是为药物滥用者（如解离剂滥用带来的慢性解离）的认知降低有显著的恢复效果。

胞磷胆碱钠，苏糖酸镁等补剂，是认知改善剂，苏糖酸镁等镁剂可以补充oder脑中缺失的镁，胞磷胆碱钠类似。

孕烯醇酮是我发现的一个NMDA受体正变构剂，它被我列为反解离剂，它相反于解离剂的机制，所以我认为它或许可以治疗慢性解离，但是目前没发现其尝试记录。

呲拉西坦等拉西坦类药品是动机增强剂，它们机理不明，不过目前看来它们改善的地方很多，尽管它们的机理不直接相反与解离剂，但是它们依旧有治疗慢性解离效果。

多奈哌齐，石杉碱甲等乙酰胆碱酯酶抑制剂是记忆增强剂，它们抑制乙酰胆碱酯酶以让乙酰胆碱含量上升，用于治疗阿尔茨海默症，目前看来可能对药物导致的认知障碍具有恢复效果。

加兰他敏也是乙酰胆碱酯酶抑制剂，与褪黑素并为梦境增强剂，它们可以让人的梦境变得丰富多彩，只是可能会出现梦游等现象。

### 欣快剂

> 例如吗啡，甲基苯丙胺，普瑞巴林，奈福泮，哌甲酯

欣快剂顾名思义，会带来直接的欣快感，它们大部分具有很强的成瘾性，需要警惕。

阿片类药品是一类可以强效镇痛并且带来欣快的药剂，它们具有极高的成瘾性与成瘾危害，并且大部分为麻醉药品。阿片类药品带来的欣快感、幸福感、梦境增强非常显著，这是其心理成瘾基础。

甲基苯丙胺等多巴胺系药品会强烈释放多巴胺让人感到极度的欣快，它们具有极高的成瘾性与危害，并且大部分都为精神药品。

奈福泮和哌甲酯等多巴胺再摄取抑制剂也能让人感到欣快，只是不如直接释放多巴胺那么强烈罢了。

### 合法成瘾品

> 尼古丁，咖啡因，乙醇，槟榔碱

尼古丁会让人产生多巴胺，使人产生欣快；乙醇让人释放内啡肽激动阿片受体，并且可以去抑制与镇静；槟榔碱让人兴奋，呈现兴奋性认知增强效果；咖啡因则是抢占腺苷受体，让人清醒。以上都有成瘾性，只是在本章节中谈到的其他药品相比显著轻微。

### 逆转剂

> 纳洛酮，氟马西尼，赛庚啶，亚甲蓝，阿托品，肾上腺素，乙酰半胱氨酸，毒扁豆碱

逆转剂是一类用于拮抗、逆转其他药物或毒物作用的药剂。

纳洛酮拮抗阿片受体，用于阿片类过量；

氟马西尼拮抗苯二氮卓位点，用于苯二氮卓类过量；

毒扁豆碱抑制乙酰胆碱酯酶，可用于抗胆碱能谵妄；

阿托品拮抗毒蕈碱受体，用于胆碱能危象；

肾上腺素用于过敏反应与休克；

亚甲蓝用于亚硝酸钠中毒；

赛庚啶可用于血清素综合征；

乙酰半胱氨酸用于对乙酰氨基酚中毒。
